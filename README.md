# Интерактивное приглашение 💗

Это готовый одностраничный сайт-приглашение, сделанный на чистом HTML/CSS/JavaScript.

## Как изменить
- Тексты находятся в `index.html`.
- Дизайн — в `style.css`.
- Логика кнопок и выбора — в `script.js`.

## Публикация
Проще всего загрузить эти три файла на Vercel, GitHub Pages или другой статический хостинг.

После публикации сайт открывается обычной ссылкой и нормально работает на телефоне.
